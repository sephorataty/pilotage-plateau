Méthode : les taux d'un groupe sont recalculés à partir des volumes (jamais de moyenne de moyennes). CA+/argu = CA+ ÷ argumentés ; Conso fiche = CA+ ÷ décrochés (taux) ; Volume conso = décrochés ÷ CA+ (fiches consommées pour un CA+, plus bas = mieux) ; CA+/heure = CA+ ÷ heures de production (estimées à partir des temps de communication les jours sans CA+) ; DMC Refus = durée moyenne des refus, pondérée par le nombre de refus. Choisir un segment ne garde que les conseillers qui y ont travaillé sur la période ; le « plateau » de référence devient alors celui du segment.
