Mettre à jour le pilotage plateau

Rien n'est envoyé sur Internet depuis cette page : les fichiers sont lus et chiffrés dans votre navigateur. Seul le fichier chiffré que vous téléverserez sur GitHub sera publié.

1Déposer les exports Excel

Un ou plusieurs fichiers au format de l'export habituel (colonnes Decrochés, CA+, C-, …, DATE et, si possible, SEGMENT). Plusieurs fichiers sont additionnés, par exemple septembre + octobre.

Glissez les fichiers ici ou cliquez pour choisir

2Choisir le code d'accès

Gardez le même code que le mois précédent pour que les responsables n'aient rien à ressaisir. Un nouveau code leur sera demandé à leur prochaine visite.

3Générer le fichier chiffré

4Publier sur GitHub

  1. Ouvrez la page de dépôt du site : github.com/sephorataty/pilotage-plateau/upload/main
  2. Glissez le fichier téléchargé. Il doit s'appeler exactement data.enc.json : si votre navigateur l'a renommé (data.enc (1).json), renommez-le avant.
  3. Cliquez sur Commit changes. Le lien des responsables affiche les nouvelles données en une à deux minutes.
